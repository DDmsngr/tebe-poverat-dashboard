# Тебе поверят. Учёт психологической помощи (прототип)

Прототип панели показателей для АНО «Тебе поверят». Демо работает на вымышленных данных.

- Показатели: новые обращения, передано специалистам, очередь на конец месяца, консультации, уникальные клиенты, ожидание, причины завершения.
- Фильтры: период, направление, специалист, проект, регион клиента.
- Загрузка старой таблицы «Консультации» (.xlsx). Файл читается в браузере и никуда не отправляется.
- Выгрузка отчёта в .xlsx за выбранный период.
- Подключение к Битрикс24 запланировано отдельным этапом (промежуточный сервис, отдающий только числа и коды).

Расчёт показателей: `src/metrics.ts`, тесты: `npm test`.

```bash
npm install
npm run dev
npm run build
```

Персональных данных клиентов в репозитории нет и быть не должно.
